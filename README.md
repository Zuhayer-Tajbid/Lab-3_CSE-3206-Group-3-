## Overview

This lab focuses on the analysis and implementation of two **Structural Design Patterns**:

* **Flyweight Pattern** — focuses on sharing common data/objects to reduce memory usage.
* **Proxy Pattern** — provides a substitute that controls or manages access to another object.
